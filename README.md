### Projetos

**[Projeto ARCA](https://github.com/Projeto-arca/PROJETO-ARCA---Grupo-4)** — sistema web de gestão de adoção e cuidado de animais, para o Programa de Proteção Animal da Prefeitura da Serra.
Node.js + Express, PostgreSQL, front em HTML/CSS/JS puro, com quatro perfis de usuário
(tutor, candidato à adoção, ONG e prefeitura). De oito grupos, o nosso foi um dos três
escolhidos para apresentar na prefeitura.

**[Vennperio](https://github.com/UVV-CC1N-26-P3/Vennperio)** — jogo multiplayer em JavaScript nos moldes do paper.io, em que a mecânica é teoria dos conjuntos.
Extensão universitária ligada à ODS 4 (Educação de Qualidade), para ensinar matemática
de ensino fundamental e médio por gamificação. Node.js, socket.io para o tempo real e
uma biblioteca de geometria para o cálculo das áreas.

**[atendimento-ia](https://github.com/guzazo/atendimento-ia)** — integração da API do Mercado Livre com a API da Anthropic, orquestrada em n8n, para automação de atendimento pós-venda.

**COMERCINOX ERP** *(repositório privado)* — descoberta, arquitetura e ferramentas
para substituir gradualmente um ERP legado. Réplica do banco em PostgreSQL, análises
em SQL sobre dado real e conferência automática de comissão em Python.
